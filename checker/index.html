이 기록은 우리 학교 시트에 저장돼요. 끝까지 하면 완주 기록이에요.

파일로 직접 열면 카메라가 막힐 수 있어요. GitHub Pages 주소(https)로 열어 주세요.

카메라로 어느 칸에 섰는지 판정해요

  • 휴대폰은 화면 쪽에 두고 매트를 바라보게 세워요. 아이들이 화면을 보며 뛸 때 몸 앞쪽이 잘 보여요.
  • 매트 앞 끝에서 2~3m, 높이는 허리쯤(의자·거치대)이 알맞아요.
  • 휴대폰은 세로로. 머리부터 발끝, 4칸이 모두 화면에 들어와야 해요.
  • 카메라를 켜면 다음 화면에서 자리가 맞는지 바로 알려 줘요.

영상은 저장하거나 보내지 않고 이 기기 안에서만 처리해요.

무엇을 할까요?
