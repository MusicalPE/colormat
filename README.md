# 색동 (색깔 매트 놀이터)

바닥에 4색 매트를 깔고 화면을 보며 뛰는 체육 놀이와, 카메라 판정 기록을 모으는 우리 학교 프로그램입니다.

- **우리 학교 기록 (처음 화면)**: https://musicalpe.github.io/colormat/
- **놀이터 (게임 모음, 단독판 v1.9.1)**: https://musicalpe.github.io/colormat/play/
- **카메라 판정기**: https://musicalpe.github.io/colormat/checker/index.html
- **전국 현황판**: https://musicalpe.github.io/colormat/board.html

## 매트 배치
왼쪽 위 빨강 · 오른쪽 위 노랑 · 왼쪽 아래 초록 · 오른쪽 아래 파랑

## 카메라 판정기
휴대폰·태블릿 카메라로 학생이 어느 칸에 섰는지 판정해 놀이터 게임을 자동 채점합니다.
카메라로 채점하는 게임: 색깔 뛰기 · 헷갈려 뛰기 · 기억 뛰기 · 방향 뛰기 · 정답 뛰기 · 그림 뛰기 · 손발 꼬기 · 얼음 꽁꽁 · 용암 피하기 (박자 뛰기은 박자 판정이 필요해 아직 빠져 있어요).
매트를 화면에 비추면 네 칸을 스스로 찾고, 사람이 매트 위에 서면 바로 시작합니다. 영상은 저장하거나 보내지 않고 기기 안에서만 처리합니다.

## 색동 라이브 (여러 매트가 함께 뛰기)
- 선생님 TV 화면: https://musicalpe.github.io/colormat/live/ (우리 학교 기록 → 관리자 메뉴 → 📺 색동 라이브에서 열면 명단·저장이 연결돼요)
- 매트마다 휴대폰·태블릿을 세우고 TV의 QR을 찍어 매트 번호와 뛸 사람을 고르면, 문제는 TV에 크게 나오고 모든 매트가 같은 문제로 동시에 뛰어요.
- 각 기기가 카메라로 판정해 정답·시도 수만 보내고(이름·영상은 보내지 않음), 끝나면 결과가 학교 시트에 승인된 카메라 기록으로 들어가요.
- 실시간 연결은 줄넘기 점프 라이브와 같은 Firebase 프로젝트를 써요. 규칙은 `live/database.rules.json`.
